你实际训练了什么

底模是 PP-OCRv5 mobile 文字识别模型。OCR 是“从图像读文字”的任务名称；这个底模是一套已经训练好的网络结构和权重。官方模型卡标注 Apache-2.0，支持中英文。

本机加载后共有 7,682,365 个网络参数，微调最后线性分类层的 2,224,585 个参数。模型文件约 31 MB。文件里还含有归一化统计量等张量，因此官方文件中浮点元素总数与 model.parameters() 的参数统计略有区别。

常见 OCR 流程为：整张图 → 检测文字框 → 裁成文字行 → 识别出字符串。本次从“文字行”开始。能读出字符串，不代表这个接口也能输出每个字在原图中的坐标；整张图片上的检测/定位是本次没有训练和测评的部分。有些一体模型会同时处理两者，但不是这次的架构和输出范围。

每一步：我做了什么，你要理解什么

步骤 本次实际动作 你需要掌握的概念
1. 定义任务与成功标准 中英文文字行识别；完成可验证的训练闭环 先明确输入、输出和“什么算对”；学习实验不要求一定涨分
2. 选底模 选择小型双语预训练识别器，固定版本与权重 复用已有知识，节省从零学习文字的成本
3. 配置环境和框架 项目内 Python 虚拟环境，PyTorch + Transformers 框架负责计算和模型加载；虚拟环境隔离依赖。沙箱是文件/命令权限边界，不是模型训练必需的一层网络，也不一定要 Docker
4. 准备数据与标注 生成 450 张图及标准答案；300 训练 / 50 验证 / 100 测试 标注是真值。这里直接使用绘图字符串，没有拿 OCR 猜测当标准答案
5. 固定 benchmark 和基线 固定数据清单、评分规则；先看验证集底模表现 Benchmark 是测试题及评分办法；baseline 是训练前成绩
6. 训练 冻结图像网络和编码器，缓存特征；用 CTC 损失更新识别头 模型预测与标准答案产生损失，梯度指出参数调整方向，优化器真正更新参数
7. 验证、选模型和保存 每 60 步评估验证集；并列时选最早的第 60 步 验证集帮助选择检查点。最终模型与“最后一次保存”可以不同
8. 独立测评和推理复核 选完模型后评测同一测试集；重新加载完整模型再次跑全量测试 测试集负责最后验收；推理只读图输出结果，不更新参数

CTC 适用于“知道整行文字，但没有逐字框”的训练：它处理图像特征序列与文字序列的对齐。推理时合并连续重复字符并去掉空白符。这里没有逐字标注或语言模型纠错。

本次采用 CPU、2 个 PyTorch 计算线程。GPU/MPS 训练兼容性尚未验证；这次运行没有使用 GPU。训练与推理使用同一套 PyTorch/Transformers 框架，没有做 Core ML 或其他部署格式转换。

训练细节和真实性证据

  • 固定随机种子；AdamW，学习率 2e-5，batch size 1，梯度裁剪 1.0，weight decay 0.001。
  • 准备 300 张训练图的特征，正式训练执行 240 次更新，使用其中 240 张图，每张一次。没有跑完一个完整训练轮次（epoch），这是刻意缩小的教学实验。
  • 第 60 / 120 / 180 / 240 步验证 CER 都为 0.36%；按预设规则选最早的第 60 步。
  • 先完成一次真实反向传播、更新、保存及恢复短测，再还原底模开始正式训练；该短测不计入 240 步。
  • 最终识别头最大参数变化为 0.000998288；权重哈希从 a9dda5867b3d688d… 变为 26b0eee021a8d8d9…。
  • 独立核对确认只改动 head.head.weight、head.head.bias，其余 1,033 个张量完全相同。
  • 保存后重新加载完整模型，使用官方预处理/后处理对全部 100 张测试图推理；前后两套预测分别与原记录逐条一致。另用独立编辑距离实现复核指标。

这说明训练实际发生了。参数变动可能只改变字符的分数，而没有改变得分最高的字符，所以输出完全相同并不矛盾。

评分怎么读

CER =（替换 + 删除 + 插入次数）÷ 标准答案字符数，越低越好。按整个数据集的字符数汇总，严格计入空格、大小写和标点，不做清洗来抬高分数。它不是“正确字符占比”的另一种严格说法，极端情况下插入很多字符可使 CER 大于 100%。

整行完全正确率要求一整行每个字符都一致，少一个空格也算该行错误。用它衡量直接交付整行文字是否可靠，会比只看平均字符错误更直观。

这次证明了什么，尚未证明什么

已经证明：这台 Mac 的 CPU 足以完成一个小型双语 OCR 识别头微调闭环；数据、真实梯度更新、模型保存、重载和独立测评均可验证。

尚未证明：真实照片准确率提升、复杂背景/大角度/手写/整页文档的识别效果、文字框定位能力、GPU 训练兼容性。合成数据使用重复的模板和字体，虽然具体文本和图像没有跨集重复，仍存在很强的风格相似性。测试集只有 100 张，本轮没有统计显著性结论。

下一步最值得做的是准备真实错例与独立标签，再针对一个错误类型设计实验；本次没有擅自开启下一轮。
